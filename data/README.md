# Data Directory

## Dataset: Experimental Band Gap of Inorganic Semiconductors (`expt_gap`)

### Source
- **Name**: `expt_gap` (Experimental Band Gap Dataset)
- **Library**: [matminer](https://hackingmaterials.lbl.gov/matminer/)
- **Matbench version**: `matbench_expt_gap`
- **Original paper**: Zhuo, Y., Mansouri Tehrani, A., & Brgoch, J. (2018). Predicting the Band Gaps of Inorganic Solids by Machine Learning. *Journal of Physical Chemistry Letters*, 9(7), 1668–1673. https://doi.org/10.1021/acs.jpclett.8b00124
- **License**: CC BY 4.0 (Creative Commons Attribution 4.0 International)

### Description
A dataset of **4,604 inorganic semiconductors** with experimentally measured optical band gaps.
Each entry contains a chemical composition string (e.g., `GaAs`, `TiO2`) and a measured band gap
value in electron-volts (eV). Band gap determines whether a material is a conductor,
semiconductor, or insulator, making it a primary design target in photovoltaics, LEDs,
and thermoelectric applications.

### Target Property
| Property | Symbol | Unit | Range |
|---|---|---|---|
| Experimental band gap | `gap expt` | eV | 0.0 – ~14 eV |

### Input Features
Raw input is the **chemical composition string**. We derive ~144 numerical features using
matminer's `ElementProperty` featurizer (Magpie preset) plus supplementary featurizers:

| Feature Group | Featurizer | Approx. # Features |
|---|---|---|
| Elemental statistics (mean, std, min, max, range) | `ElementProperty` (Magpie) | 132 |
| Stoichiometric features | `Stoichiometry` | 5 |
| Valence orbital occupancy | `ValenceOrbital` | 4 |
| Ion property (avg ionic character) | `IonProperty` | 2 |
| Band center estimate | `BandCenter` | 1 |
| **Total (before filtering)** | | **~144** |

The feature cache preserves all extracted descriptors. For each training run,
near-constant features (variance < 1e-6) and highly correlated pairs (|r| > 0.95)
are filtered using training rows only (the currently labeled samples during active
learning), typically leaving **~100–120 features**.

### Missing Values
None. The Matbench version of this dataset is pre-cleaned with no missing target values.
A small number of compositions (< 1%) may fail featurization due to uncommon elements
— these rows are dropped automatically during preprocessing with a warning.

### Preprocessing
See `backend/ml/data/preprocessing.py` for the full pipeline:
1. Load raw data (composition string + target)
2. Convert composition strings to `pymatgen.Composition` objects
3. Apply matminer featurizers to extract numerical descriptors
4. Drop featurization failures
5. Split into training, validation, and held-out test partitions as applicable
6. Fit missing-value imputation and near-constant filtering on training rows only
7. Fit correlated-feature filtering on training rows only (|r| > 0.95, keep first)
8. Apply fitted feature selection to validation/test/pool rows without refitting
9. Fit StandardScaler normalization on training rows only
10. Optional: fit PCA on training rows for GP scalability

### How to Download

#### Option A — Via matminer (recommended)
```bash
pip install matminer pymatgen
python -c "
from matminer.datasets import load_dataset
df = load_dataset('matbench_expt_gap')
df.to_csv('data/raw/matbench_expt_gap.csv', index=False)
print(f'Downloaded {len(df)} samples')
"
```

#### Option B — Via the application
The backend automatically downloads and caches the dataset on first startup if not present.
See `backend/app/services/dataset_service.py`.

#### Option C — Manual download
Visit: https://ml.materialsproject.org/projects/matbench_expt_gap
Download the CSV and place it in `data/raw/matbench_expt_gap.csv`.

### Substituting Another Dataset
The pipeline is designed to accept any CSV with:
- A **composition column** (chemical formula strings) named `composition`
- A **continuous target column** (any name, configurable)

Candidate substitutes:
| Dataset | Target | N | Source |
|---|---|---|---|
| `matbench_mp_gap` | DFT band gap (eV) | 106,113 | Materials Project |
| `matbench_mp_e_form` | Formation energy (eV/atom) | 132,752 | Materials Project |
| `matbench_perovskites` | Heat of formation (eV) | 18,928 | Materials Project |

For large datasets (N > 10,000), the GP model is automatically replaced by an RF ensemble.
